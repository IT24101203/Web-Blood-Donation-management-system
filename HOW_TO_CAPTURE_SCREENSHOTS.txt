PART 2: RUNNING APPLICATION FOR CONSOLE OUTPUT
-----------------------------------------------

Step 1: Open PowerShell in your project folder
   Right-click project folder → "Open in Terminal"

Step 2: Run the application
   Command: mvn spring-boot:run
   
Step 3: Wait for application to start
   Look for: "Started [YourApplication] in X seconds"
   
Step 4: Open web browser
   URL: http://localhost:8080
   
Step 5: Login as Hospital Staff
   - Navigate to Staff Login
   - Enter hospital staff credentials
   
Step 6: Approve a Blood Request
   - Go to Blood Requests section
   - Find a pending request
   - Click "Approve" button
   
Step 7: Switch to PowerShell window
   - You should see Observer Pattern output
   - Screenshot this output immediately!

TROUBLESHOOTING
---------------

Problem: Application won't start
Solution: Check if another application is using port 8080
   Command: netstat -ano | findstr :8080
   Kill process: taskkill /PID [process_id] /F

Problem: No blood requests to approve
Solution: Login as receiver first and create a blood request

Problem: Console output not showing
Solution: Check your application.properties for logging settings
